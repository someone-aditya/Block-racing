# Block Racing Game - Godot Version

A simple block-style racing game built with Godot 4.x

## Features

- 🎮 Keyboard controls (WASD or Arrow keys)
- 🚗 Smooth car physics with tilt effects
- 🏎️ Progressive difficulty (speed increases with score)
- 💥 Particle effects and lighting
- 📱 Mobile-friendly (portrait orientation)
- 🌐 Web export ready

## Controls

- **Left/Right** or **A/D** - Steer
- **Up** or **W** - Accelerate
- **Down** or **S** - Brake

## Play Online

[Play on GitHub Pages](https://yyuunnii.github.io/racing-game-godot/)

## Development

### Requirements

- Godot 4.2+

### Export to Web

1. Open project in Godot
2. Project → Export → Add → Web
3. Export to `docs/` folder
4. Push to GitHub for Pages deployment
